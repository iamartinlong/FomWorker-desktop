# fom-brand · 品牌 tokens

> 品牌视觉与设计 tokens（公司 logo 采样）。设计文档：`docs/02-设计/品牌视觉与设计Tokensv0.1.md`。

## 内容

| 文件 | 说明 |
|---|---|
| `tokens.css` | 品牌色 + 语义色 + **shadcn / Tailwind 4 token 映射（亮/暗）**。 |

## 品牌三色

- **品牌蓝**（主）`#038AC6`
- **品牌琥珀**（辅）`#FCB513`
- **品牌墨灰**（字）`#4E4B47`

## 用法

- `fom-web` 引入 `tokens.css`，覆盖 `shadcn-admin` 的 CSS 变量。
- 自定义 tokens：`--brand-blue` / `--brand-amber` / `--brand-ink`。

> 产品自有 logo 出来后在此替换/扩展。
